# CAN Communication Dashboard

## Project Overview

Developed a CAN (Controller Area Network) Communication Dashboard to understand and monitor communication between electronic control units (ECUs) using the CAN protocol.

The project focuses on CAN message transmission, reception, and monitoring of communication data.

## Technologies Used

* Programming Language: Embedded C
* Communication Protocol: CAN
* Microcontroller: PIC18F4580 (if used)
* Development Environment: MPLAB X IDE
* Compiler: XC8

## Features

* CAN Message Transmission
* CAN Message Reception
* CAN Frame Monitoring
* CAN Identifier Handling
* Data Field Processing
* Error Detection using CRC

## Concepts Learned

* CAN Protocol Architecture
* CAN Data Frame
* CAN Arbitration
* CAN Identifier
* CRC Error Detection
* CAN Bus Communication

## Applications

* Automot
